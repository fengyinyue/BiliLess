# BiliLess

一个可以按类型隐藏哔哩哔哩推荐卡片的 Chrome / Edge 浏览器扩展。

## 功能

- 可折叠的内容类型筛选：广告推广、直播、番剧、国创、电影、电视剧、纪录片、漫画和课程
- 勾选需要屏蔽的视频分区
- 勾选需要屏蔽的分区或具体子分区
- 提供完整的新版一级分区和子分区，可搜索、全选或清空
- 按 UP 主昵称或 UID 屏蔽视频卡片
- 悬停视频卡片即可屏蔽对应 UP 主、具体子分区或整个一级分区
- 使用 MiniMax、OpenAI、DeepSeek、Google Gemini、通义千问或自定义兼容接口进行 AI 语义筛选
- 总开关与当前页面屏蔽数量
- 自动处理滚动加载和页面动态更新的内容

直播、影视剧和漫画开关默认关闭，可以在扩展弹窗中按需开启。

## 安装

1. 打开 `chrome://extensions`（Edge 使用 `edge://extensions`）。
2. 开启右上角的“开发者模式”。
3. 点击“加载已解压的扩展程序”，选择本项目目录。
4. 刷新已经打开的哔哩哔哩页面。

修改代码后，在扩展管理页点击 BiliLess 卡片上的“重新加载”，再刷新哔哩哔哩页面。

## 隐私

扩展只检查 B 站页面中的卡片元素和链接。启用分区或 UP 主规则后，会根据视频 BV 号请求 B 站公开的视频信息接口，以取得分区和作者；数据不会发送给第三方。所有开关和名单均保存在浏览器的扩展同步存储中。

分区识别优先使用接口返回的 `tid_v2`，其次使用旧版 `tid`，最后才使用 `tname_v2`、`tname` 和页面角标，以兼容分区名称为空的内容。

启用 AI 筛选后，视频标题、分区、UP 主和用户填写的筛选偏好会发送至用户选择的 AI 服务。API Key 和各服务的接口配置仅保存在 `chrome.storage.local`，不会随浏览器账号同步；其他筛选设置使用同步存储。AI 请求可能产生相应的 API 用量。
